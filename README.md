# Shopify Website

A Shopify storefront designed and customized primarily using the Shopify Theme Editor, with minor code adjustments for styling and functionality.

## Overview

This project involved designing and configuring a Shopify storefront with a focus on clear navigation, visual consistency, usability, and responsive design.

## My Role

- Customized the website using the Shopify Theme Editor
- Designed page layouts and site structure
- Configured product and collection pages
- Set up navigation and storefront content
- Adjusted layouts for desktop and mobile
- Made minor code edits to refine styling and functionality

## Platform & Tools

- Shopify
- Shopify Theme Editor
- Custom code adjustments
- HTML / CSS / Liquid where applicable

## Key Features

- Responsive storefront design
- Product and collection organization
- User-friendly navigation
- Consistent visual styling across pages
- Mobile-friendly layout
- Customized sections and page components
